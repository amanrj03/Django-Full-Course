14. path() vs re_path()

Use re_path() when you genuinely need regex matching.

26. Form Validation

Built-in:

Custom field validation:

PYTHON
def clean_name(self):

    name = self.cleaned_data["name"]

    if " " in name:
        raise forms.ValidationError(
            "Spaces are not allowed."
        )

    return name

Cross-field validation:

PYTHON
def clean(self):

    cleaned_data = super().clean()

    password = cleaned_data.get("password")
    confirm = cleaned_data.get("confirm")

    if password != confirm:

        raise forms.ValidationError(
            "Passwords do not match."
        )

    return cleaned_data

68. Cookie vs Session

Very important viva question.

Cookie Session
Stored by browser Usually stored server-side
Client sends cookie data Browser commonly sends session ID
Can directly store small data Used for server-managed state
Client-controlled Better for server-managed state
request.COOKIES request.session

Django's default database-backed sessions typically store session data server-side and use a sessionid cookie to identify the session.

78. The Most Important Django Coding Pattern

If you get a form-based coding question, think:

PYTHON
def my_view(request):

    if request.method == "POST":

        form = MyForm(
            request.POST
        )

        if form.is_valid():

            # process data

            return redirect(
                "success"
            )

    else:

        form = MyForm()

    return render(
        request,
        "form.html",
        {
            "form": form
        }
    )

This pattern solves a huge number of Django questions.
