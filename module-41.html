6. Why UserCreationForm?

Django already provides a form specifically designed for creating users.

It handles things such as:

TEXT

password
password confirmation
password validation

So we don't need to manually implement password hashing.

7. password1 and password2

The registration form asks for:

These correspond to:

Django checks that they match.

For example:

StrongPassword123

14. Login View

Now:

PYTHON
from django.contrib.auth import (
    authenticate,
    login,
    logout
)

from .forms import (
    RegisterForm,
    LoginForm
)

Then:

PYTHON
def login_view(request):

    if request.method == "POST":

        form = LoginForm(
            request.POST
        )

        if form.is_valid():

            username = form.cleaned_data[
                "username"
            ]

            password = form.cleaned_data[
                "password"
            ]

            user = authenticate(
                request,
                username=username,
                password=password
            )

            if user is not None:

                login(request, user)

                return redirect(
                    "dashboard"
                )

            form.add_error(
                None,
                "Invalid username or password"
            )

    else:

        form = LoginForm()

    return render(
        request,
        "accounts/login.html",
        {
            "form": form
        }
    )

53. Viva Questions

Q1. What is authenticate()?

It verifies the supplied credentials using Django's authentication system and returns a User object if authentication succeeds, otherwise None.

Q2. What does login() do?

It establishes the authenticated user's session so subsequent requests can identify the user.

Q3. What does logout() do?

It logs the user out by ending the authenticated session state.

Q4. Why is login() required after authenticate()?

Because authenticate() verifies credentials, while login() establishes the authenticated session.

Q5. What is UserCreationForm?

It is Django's built-in form for creating users with proper password handling and validation.

Q6. Why use UserCreationForm?

It avoids manually implementing user creation and password hashing/validation logic.

Q7. What is @login_required?

A decorator that restricts a view to authenticated users.

Q8. What happens when an unauthenticated user accesses a protected view?

Django redirects them to the configured login URL, commonly preserving the original destination using a next parameter.

Q9. What is request.user?

It represents the user associated with the current request.

Q10. What is the relationship between login and sessions?

Django's authentication system uses the session framework to maintain authenticated state across requests.

54. Interview Question

"Explain the Django login process."

Strong answer:

"The user submits a login form using POST. I validate the form and obtain the username and password from cleaned_data. I pass them to authenticate(). If it returns a User object, I call login(request, user), which establishes the authenticated session. On subsequent requests, Django uses the session information to associate the request with the authenticated user, which is available through request.user. If authentication fails, I return the form with an appropriate error."

55. Interview Question

"Explain registration."

Strong answer:

"I use Django's UserCreationForm to validate the registration data and handle password creation correctly. If the form is valid, I call form.save() to create the User and then redirect to the login page using the POST-Redirect-GET pattern."

63. Coding Question

Complete basic login.

PYTHON
def login_view(request):

    if request.method == "POST":

        username = request.POST.get(
            "username"
        )

        password = request.POST.get(
            "password"
        )

        user = authenticate(
            request,
            username=username,
            password=password
        )

        if user is not None:

            login(request, user)

            return redirect(
                "dashboard"
            )

        return HttpResponse(
            "Invalid credentials"
        )

    return render(
        request,
        "login.html"
    )
