If you mean all important Django imports you should remember for your syllabus/exams, here is a compact cheat sheet.

1. Basic Django Imports

PYTHON
from django.http import HttpResponse
from django.shortcuts import render, redirect, get_object_or_404
from django.urls import path, include, reverse, re_path
Import Used for
HttpResponse Return plain/text HTTP response
render Return HTML template with context
redirect Redirect to another URL
get_object_or_404 Get object or automatically raise 404
path Define URL patterns
include Include app URLs
reverse Generate URL from URL name
re_path Regex-based URL

2. Views

PYTHON
from django.http import HttpResponse, JsonResponse, Http404
from django.shortcuts import render, redirect, get_object_or_404

JSON response

PYTHON
from django.http import JsonResponse
PYTHON
return JsonResponse({"name": "Aman"})

Raise 404

PYTHON
from django.http import Http404
PYTHON
raise Http404("Student not found")

3. URLs

PYTHON
from django.urls import path, include, reverse, re_path

Typical:

PYTHON
from django.urls import path
from . import views

With regex:

PYTHON
from django.urls import re_path

4. Models

PYTHON
from django.db import models

Example:

PYTHON
class Student(models.Model):
name = models.CharField(max_length=100)
age = models.IntegerField()

Important field-related imports

Usually you don't import individual fields.

❌ Don't do:

PYTHON
from django.db.models import CharField

Instead:

PYTHON
from django.db import models

and use:

PYTHON
models.CharField()
models.IntegerField()
models.ForeignKey()

5. ORM — Querying

Basic model import:

PYTHON
from .models import Student

or from another app:

PYTHON
from students.models import Student

Q objects

PYTHON
from django.db.models import Q
PYTHON
Student.objects.filter(
Q(course="CSE") | Q(course="ECE")
)

F expressions

PYTHON
from django.db.models import F
PYTHON
Student.objects.update(
marks=F("marks") + 5
)

Aggregation

PYTHON
from django.db.models import Count, Sum, Avg, Max, Min

Example:

PYTHON
Student.objects.aggregate(
Avg("marks")
)

Common combined import

PYTHON
from django.db.models import Q, F, Count, Sum, Avg, Max, Min

6. Forms

PYTHON
from django import forms

class StudentForm(forms.Form):

from django import forms

raise forms.ValidationError("Invalid marks")

from django import forms

class StudentForm(forms.ModelForm):

8. Authentication

These are extremely important:

PYTHON
from django.contrib.auth import authenticate, login, logout

authenticate()

PYTHON
user = authenticate(

login(request, user)

logout()

PYTHON
logout(request)

10. UserCreationForm

PYTHON
from django.contrib.auth.forms import UserCreationForm

Usually combined with:

PYTHON
from django import forms
from django.contrib.auth.models import User
from django.contrib.auth.forms import UserCreationForm

Example:

PYTHON
class RegisterForm(UserCreationForm):
email = forms.EmailField(required=True)

class Meta:
model = User
fields = ["username", "email", "password1", "password2"]

13. Admin

PYTHON
from django.contrib import admin

PYTHON
from .models import Student

PYTHON
admin.site.register(Student)

Customized admin:

PYTHON
from django.contrib import admin
from .models import Student

14. Cookies

Cookies usually don't require a special import.

Use:

PYTHON
request.COOKIES

and:

PYTHON
response.set_cookie()
response.delete_cookie()

Example:

PYTHON
from django.http import HttpResponse

def set_cookie(request):
response = HttpResponse("Cookie set")
response.set_cookie("username", "Aman")
return response

15. Sessions

Sessions also generally don't require a special import.

PYTHON
request.session["username"] = "Aman"
PYTHON
request.session.get("username")

For authentication logout, use:

PYTHON
from django.contrib.auth import logout

16. CSRF

Template

No Python import needed:

HTML
{% csrf_token %}

CSRF decorator

PYTHON
from django.views.decorators.csrf import csrf_exempt

Then:

PYTHON
@csrf_exempt
def my_view(request):
...

⚠️ csrf_exempt disables CSRF protection, so don't use it casually.

Other useful imports:

PYTHON
from django.views.decorators.csrf import ensure_csrf_cookie
from django.views.decorators.csrf import csrf_protect
