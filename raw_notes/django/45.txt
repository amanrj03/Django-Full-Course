If you mean **all important Django imports you should remember for your syllabus/exams**, here is a compact cheat sheet.

## 1. Basic Django Imports

```python
from django.http import HttpResponse
from django.shortcuts import render, redirect, get_object_or_404
from django.urls import path, include, reverse, re_path
```

| Import | Used for |
| ------------------- | ------------------------------------- |
| `HttpResponse` | Return plain/text HTTP response |
| `render` | Return HTML template with context |
| `redirect` | Redirect to another URL |
| `get_object_or_404` | Get object or automatically raise 404 |
| `path` | Define URL patterns |
| `include` | Include app URLs |
| `reverse` | Generate URL from URL name |
| `re_path` | Regex-based URL |

# 4. Models

```python
from django.db import models
```

Example:

```python
class Student(models.Model):
name = models.CharField(max_length=100)
age = models.IntegerField()
```

### Important field-related imports

Usually you **don't import individual fields**.

❌ Don't do:

```python
from django.db.models import CharField
```

Instead:

```python
from django.db import models
```

and use:

```python
models.CharField()
models.IntegerField()
models.ForeignKey()
```

# 5. ORM — Querying

Basic model import:

```python
from .models import Student
```

or from another app:

```python
from students.models import Student
```

### Q objects

```python
from django.db.models import Q
```

```python
Student.objects.filter(
Q(course="CSE") | Q(course="ECE")
)
```

### F expressions

```python
from django.db.models import F
```

```python
Student.objects.update(
marks=F("marks") + 5
)
```

### Aggregation

```python
from django.db.models import Count, Sum, Avg, Max, Min
```

Example:

```python
Student.objects.aggregate(
Avg("marks")
)
```

### Common combined import

```python
from django.db.models import Q, F, Count, Sum, Avg, Max, Min
```

# 14. Cookies

**Cookies usually don't require a special import.**

Use:

```python
request.COOKIES
```

and:

```python
response.set_cookie()
response.delete_cookie()
```

Example:

```python
from django.http import HttpResponse

def set_cookie(request):
response = HttpResponse("Cookie set")
response.set_cookie("username", "Aman")
return response
```

# 16. CSRF

### Template

No Python import needed:

```html
{% csrf_token %}
```

### CSRF decorator

```python
from django.views.decorators.csrf import csrf_exempt
```

Then:

```python
@csrf_exempt
def my_view(request):
...
```

⚠️ `csrf_exempt` disables CSRF protection, so don't use it casually.

Other useful imports:

```python
from django.views.decorators.csrf import ensure_csrf_cookie
from django.views.decorators.csrf import csrf_protect
```
